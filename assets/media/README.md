本目录保存四个项目的本地高清录屏，页面通过 content/projects.json 的 demoSrc 引用，显示时不拉伸。

傩场原片 nuofield-demo.mp4（约 132 MiB）在本地保留、不提交 Git。公开发布使用 nuofield-demo-web.mp4（约 56 MiB），保持原片 1920×1080、60fps，H.264 CRF18 / slow 编码；音乐音轨直接复制，前后哈希一致。其余三个录屏仅作 faststart 封装重排，视频与音频流哈希均保持原样。四个视频的索引均在文件头部，便于网页边下载边播放。详见 qa/RELEASE.md。

PAWTERN 在手机样机内静音自动循环播放，无人工控制。三个大视频使用米色圆角边框与播放、进度、音量控制；手动暂停状态会保留到再次点击播放。傩场默认启用配乐，浏览器限制有声自动播放时显示“播放影片 · 开启配乐”。离开可见区域或切换后台时暂停。

demoCrop 按源视频像素配置 [左, 上, 右, 下]。WoodLab 为 [2, 2, 6, 2]，追花为生为 [2, 2, 4, 2]，只在网页显示窗口裁去录屏边缘，不改动源文件。窗口按裁后比例显示，视频使用统一缩放比例。
