# Opening 与档案音效验收

本轮基于现有封面及本地 Figma 导出素材增加动画与声音接口。没有修改 Figma 文件、作品图、书页顺序、视频文件、最终页面构图或已有项目链接。

## 最终时间轴

动画时间从封面本地素材及字体完成解码后开始，标准模式 **4880ms**。加载等待及后台/竖屏暂停不计入动画时间。

| 阶段 | 时间 |
| --- | --- |
| 纸面展开 | 0–1120ms，120ms 开始释放 |
| WELCOME 淡入 | 840–1350ms |
| WELCOME 停留 / 淡出 | 1350–1900ms / 1900–2300ms |
| 蓝色档案夹摩擦上移 | 2350–3400ms |
| 三枚回形针 | 3480、3600、3720ms 开始，各 220ms |
| 原 Portfolio 图片显现 | 3840–4380ms |
| CTA 渐显并解锁 | 4480–4880ms |

Portfolio 标题显现后，直接衔接 CTA 渐显，不显示横线。三片分页已经烘焙在原文件夹图片中，沿用原图片，不额外拆分。

Reduced Motion 总长 **3030ms**，纸面 **350ms**。保留纸面、WELCOME、文件夹、回形针、标题、CTA 的顺序，取消卷边、透视、超宽和摩擦路径。声音偏好独立保存。

## 纸面与物理入场

`scripts/opening.js` 使用有限生命周期 RAF 计算纸面宽度及左右边缘位置，CSS 伪元素画出暖白纸边的亮面、暗面和约 2px 侧面；卷边从约 27px 收窄，rotateY 从 ±36° 回到 0，手机降至 ±26°。没有卷轴配件，也没有 3D 库。

右侧比左侧晚 **25ms**，其余时间略压缩以共同在 1120ms 落平。最后宽度轻微超过视口后回到 100%。纸纹没有横向拉伸：展开区域内部维持原始纹理尺度，中心随两边实际展开位置轻微移动。

纸面复用 `assets/global/background-original.png`，同时匹配现有 body 背景及缩放后的 stage 背景的尺寸、旋转、裁切与坐标。落平时删去纸面，原页面直接接管；六个尺寸都做了截图像素差异检查。

文件夹使用 Web Animations API 七段确定性关键帧，时间比例为 `0 / .24 / .43 / .59 / .74 / .87 / 1`，横向位移 `7 / -3 / 4 / -2 / 2 / -1 / 0px`，旋转 `.65 / -.28 / .22 / -.12 / .08 / 0 / 0deg`，纵向按 `180 / 128 / 90 / 62 / 35 / 14 / 0` 的比例，从实际视口底部外回到原位。旋转屏幕时重新计算距离，固定路径不随机抖动。

## 生命周期与声音

- 仅 Cover 首次打开或刷新播放；SPA 内部导航不重复。Choose、About、Archive、Other 及四个项目直接加载和刷新自身，不再插入首页动画。
- CTA 全部出现前 stage 为 inert，鼠标、触摸及滚动快捷键不能提前导航。
- 后台和手机/iPad 竖屏暂停时间轴；转回横屏继续。原有竖屏旋转提示保留。
- 结束后删除 overlay、卷边，取消全部 WAAPI/RAF 及临时监听；无持续 opening 动画。
- AudioManager 位于 `scripts/audio-manager.js`：Web Audio 解码、主增益 0.54、分事件音量、三声并发上限、短淡出、防抖、不连续重复的翻页变体、静音保存和清理集中管理。
- 初次用户手势解除 AudioContext 限制；未授权或素材未到位时立即跳过该次声音，不排队、不补播，不阻塞视觉。
- 右上角 44px 点击区配低透明度 SVG 图标，没有背景框。`portfolio_sound_muted` 保存静音偏好。
- 傩场视频的配乐与播放器音量不受交互音效开关影响。
- **16 个音效 MP3 均待提供**，文件名和时长见 `assets/audio/README.md`。`npm.cmd run audio:sync` 更新可用文件清单，启动命令也会自动扫描。当前不请求缺失的 MP3。

## 实际验证

- `node tools/verify-opening.mjs`：五次 CDP `Page.reload({ignoreCache:true})` 且清空缓存；早期误触、内部返回、静音刷新保存、深链、缺音频回退、零残留动画、实际翻页/拖拽/Other 音效映射通过。
- 测量自自动化捕获 playing 状态起至 ready 的时间为 4624、4880、4880、4881、4881ms；首次捕获发生在动画开始后，定义时间轴始终为 4880ms。
- 六种视口：1568×900、1920×1080、1440×900、1366×768、iPad Landscape 1024×768、Phone Landscape 844×390。检查中央窄纸、落平纹理、WELCOME、封面最终态。另测 390×844 竖屏恢复。
- 专门检查竖屏→844×390 后文件夹起始距离重新算为 804.55 源画布像素，完成状态正常。
- `npm.cmd run verify`：全场景导航、四本书、拖拽保存、Other 浏览、响应式通过。
- `node tools/verify-touch.mjs`：真实触屏事件、翻页、旋转、返回、124 个本地清单素材与44页书页通过。
- `node tools/verify-media.mjs`：傩场音轨解码、自动播放限制回退、三个视频控制、PAWTERN 自动播放与比例通过。
- `node tools/verify-reveal.mjs`：About/Archive 原有逐层入场、原始最终布局、返回保存及转场取消通过。
- 所有检查无 console error / pageerror。声音引擎并发与静音用内存中的无声测试 Buffer 验证；因真实音频尚未提供，**未进行耳机/笔记本扬声器音色与响度试听**。视口测试来自本地 Edge 浏览器模拟，不代表实体 iPad/iPhone Safari 测试。
